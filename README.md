# Ledgelings

Native macOS app. Tiny creatures crawl around the **edges of your screens** —
along the borders, over the corners, between monitors.

Ambient, click-through, menu-bar only. Not a game, not a widget.

**Status:** empty repo, brief only. No code yet.

See [BRIEF.md](BRIEF.md) for the actual plan, the hard parts, and the MVP definition.

## Stack

- macOS 26+, Swift 6, Xcode 27
- SwiftUI shell + AppKit overlay windows
- Apple Silicon
